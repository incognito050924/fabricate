# fabricate

의도 형성을 등뼈로 삼는 에이전트 작업 하네스.

사람과 에이전트가 같은 뜻을 공유할 때 문제 해결의 성공률이 가장 높다. 이 하네스는 그 공유 이해를
느낌이 아니라 **확인 가능한 술어**로 만든다. 인터뷰가 나중에 얹는 기능이 아니라 처음부터 등뼈다.

## 창립 계약

`contract/`는 읽기 전용이다. 이 저장소가 만들어야 하는 것이 무엇인지는 전부 거기에 있고, 요약이 아니라
원문이다.

- `original-request.md` — 사용자가 쓴 원 요청과 그 뒤 확정된 범위 개정 기록
- `criteria.json` — 69개 조건 (기계 운반체, 문안 verbatim)
- `criteria.md` — 같은 69개 조건의 읽기용 판본
- `contract-draft.md` — 조건별 근거와 7묶음 구조
- `research-report.md` — 의도 형성 품질 조사 전문
- `reviews/` — 착수 전 적대 심의 세 건 (설계 접근 · 커버리지 · 충실 구현 가능성)

계약 문안은 손대지 않는다. 조건을 어떻게 판정하는지(판정 기준)는 별도 산출물이며, 그것이 사람의
검토를 받는 유일한 관문이다.
