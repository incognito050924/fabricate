# fabricate

에이전트에게 일을 시키기 전에, **무엇을 시키는 것인지 먼저 붙잡는 Claude Code 플러그인.**

사람과 에이전트가 같은 뜻 위에 설 때 일이 가장 잘 풀린다. 문제는 "같은 뜻"이 대개 느낌으로만
있다는 것이다 — 대화가 길어지면 에이전트는 사용자의 말을 요약하고, 요약이 원문 자리를 차지하고,
다음 세션은 그 요약 위에서 시작한다. fabricate 은 그 자리에 **확인할 수 있는 기록**을 놓는다.

## 무엇을 하나

두 개의 명령이 있다.

```
/fabricate:deep-interview "<하고 싶은 일을 그대로 쓴다>"
```

요청이 두 갈래 이상으로 읽히거나, 무엇이 되면 끝인지 아직 못 적겠을 때 연다. 에이전트가 한 번에
하나씩 묻고, 답을 받을 때마다 **"나는 이렇게 읽었다"를 사용자에게 보여 확인받는다.** 끝나면
디스크에 **잠긴 기록** 하나가 남는다 — 사용자가 쓴 원문 그대로, 그리고 "이 일은 무엇이 참일 때
끝나는가"를 적은 문장들.

```
/fabricate:seed <잠긴 기록의 id>
```

다른 세션이나 다른 에이전트가 그 기록을 읽고 **같은 뜻 위에서 이어 일한다.** 앞의 대화를 복원하지
않는다. 복원할 필요가 없도록 기록이 만들어져 있다.

## 왜 대화만으로는 안 되나

인터뷰는 에이전트가 성실하기를 바라는 대신, **성실하지 않으면 진행이 막히도록** 되어 있다.

- **사용자의 원문이 모델 손을 안 거친다.** 명령을 치는 순간 훅이 그 문장을 바이트 그대로 파일에
  적는다. 에이전트는 그것을 요약해 치울 수 없다.
- **적지 않은 턴은 끝나지 않는다.** 인터뷰가 열려 있는데 기록이 안 늘어난 채 턴을 끝내려 하면
  Stop 훅이 막고 사유를 돌려준다. "물어봤다고 치고" 넘어가는 경로가 없다.
- **질문이 사용자에게 가기 전에 다른 눈이 읽는다.** 이 대화를 전혀 못 본 검토자가 질문 문안만 받아,
  대화 맥락 없이도 답할 수 있는지 판정한다. 못 답할 문안은 사용자에게 안 나간다. 마지막에 잠길
  목표 문장도 같은 검토를 거친다.
- **덜 끝난 인터뷰는 안 닫힌다.** 아직 안 풀린 물음이 남았거나, 사용자가 한 말 중 어느 질문에도
  안 걸린 조각이 있거나, 근거 없이 "해결됐다"고만 적힌 것이 있거나, 사용자가 확인해 주지 않은
  되읽기가 남았으면 — 닫기가 거부하고 무엇이 왜 남았는지 말한다.
- **사용자가 먼저 꺼낸 말이 목표에서 새지 않는다.** 반박이나 방향 수정은 원문 그대로 따로 적히고,
  잠글 때 그 하나하나가 목표 문장에 담겼는지 아니면 왜 뺐는지를 대야 한다.

## 남는 것

```
.fabricate/
  sessions/<id>/
    request.txt      사용자가 친 원문 (훅이 바이트 그대로 적는다)
    ledger.jsonl     인터뷰의 모든 걸음 — 질문·답·되읽기·확인·반박·모순·판정
    hooks.jsonl      훅이 언제 무엇을 봤는지
  intent/<id>.json   잠긴 기록 — 원문 + 목표 문장 + 그 문장들의 해시
```

잠긴 기록은 해시로 묶여 있어서, 나중에 목표 문장이 조용히 바뀌면 드러난다.

## 일이 끝났는지 기계에게 묻기

잠긴 기록이 있으면, 목표 문장마다 "이걸 돌려서 통과하면 참"이라고 명령을 붙여 둘 수 있다.

```sh
fabricate check record --intent <id> --goal 0 --command "bun test"
fabricate check <id>
```

`check` 는 붙여 둔 명령을 실제로 돌려서 판정한다. 증거가 없거나, 명령이 실패하거나, 다른 기록의
증거를 가져다 쓰면 통과하지 않는다.

## 설치

Claude Code 플러그인이다. 저장소 뿌리에서 **이 한 줄**을 돌리고 Claude Code를 재시작한다.

```sh
bun link && claude plugin marketplace add ./ && claude plugin install fabricate@fabricate-local
```

세 토막이 각각 하는 일: `bun link`가 `fabricate` 명령을 PATH에 올리고(인터뷰가 매 턴 이걸 부른다 —
플러그인 뿌리 경로는 모델의 셸 환경에 오지 않는다, 2026-07-29 실측), 나머지 둘이 슬래시 명령과
훅 셋을 등록한다.

- 같은 줄을 다시 돌려도 결과가 같다 — 호스트가 *already installed*로 no-op 처리한다.
- 마켓플레이스 소스가 `directory`라 **저장소를 옮기면 등록된 경로가 낡는다.** 옮긴 뒤에는
  옮긴 자리에서 같은 줄을 다시 돌린다.
- 지우려면: `claude plugin marketplace remove fabricate-local && bun unlink`.

## 도구 사슬

Bun + TypeScript(strict).

언어 규약은 표면마다 다르다.

- **코드 · 주석 · 프롬프트**(`skills/*/SKILL.md` · `agents/*.md`) — 영어. 사용자에게 안 보인다.
- **CLI 출력** — 영어. 이것을 읽는 것은 에이전트다.
- **사용자에게 보이는 문장** — 에이전트가 쓴다. **사용자가 쓴 언어를 따라간다.** CLI가 낸 상태
  블록이나 거부 사유를 사용자에게 옮길 때도 사용자의 언어로 옮긴다. 다만 **사용자가 쓴 문장을
  인용하는 자리는 원문 그대로** 둔다.
